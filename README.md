# Emby 封面工坊

一个专门为 Emby 媒体库/合集自动生成封面的工具网站。它会读取媒体库与合集内的影片封面，按模板（影片封面拼图 + 库名标题）合成一张新封面，并通过 Emby API 自动写回，支持 Webhook 入库自动更新与 cron 定时更新，开箱即用 Docker 部署。

## 功能特性

- 🔌 通过 API 密钥连接 Emby，自动发现所有媒体库与合集
- 🖼️ 使用影片真实封面合成封面：影片海报网格 + 库名标题 + 数量副标题
- 🎨 可配置封面尺寸、列数、影片数量、背景渐变色、标题颜色、圆角、字体等
- ⚡ Emby Webhook 入库/更新/删除后自动重新生成相关封面
- ⏰ cron 定时同步（默认每 6 小时，可自定义），只对有变化的合集重新生成
- 🔒 可选访问令牌，保护管理界面
- 📦 Docker + docker-compose 一键部署，内置中文字体

## 快速开始（Docker）

```bash
docker compose up -d --build
```

启动后打开 http://服务器IP:3000 。

首次启动会自动生成 Webhook 地址和访问令牌（如有），在服务日志或界面「设置」页可见。

## 首次使用

1. 在 Emby 中创建 API 密钥：**控制台 → 高级 → API 密钥 → 新建 API 密钥**（需要管理员权限）。
2. 打开封面工坊界面 →「设置」。
3. 填写 Emby 服务器地址（如 `http://192.168.1.100:8096`，无需带 `/emby`）和 API 密钥。
4. 点击「测试连接」，确认成功。
5. 进入「合集管理」，勾选需要自动生成封面的媒体库/合集（默认新发现的全部启用）。
6. 点击「立即同步」或对单个合集点击「更新」。

生成成功后，封面会自动上传为 Emby 中对应媒体库/合集的封面图，在 Emby 首页即可看到效果。

## 配置 Webhook（入库自动更新）

1. 在 Emby 安装官方 **Webhooks** 插件（控制台 → 插件 → 目录 → Webhooks）。
2. 在插件设置中，URL 填写封面工坊「概览」或「设置」页显示的 Webhook 地址（带 token）。
3. 事件建议勾选：**项目已添加（Item Added）**、**项目已更新（Item Updated）**、**项目已移除（Item Removed）**、**媒体库新建（Library New）**。
4. 保存后，影片入库/更新时会触发封面工坊自动同步（默认防抖 20 秒，可在设置中调整）。

> 如果没有安装 Webhooks 插件，定时同步（默认每 6 小时）仍然会兜底更新封面。

## 定时更新

「设置 → 自动更新」中的 cron 表达式默认 `0 */6 * * *`（每 6 小时），支持标准 5 段格式：

```
分 时 日 月 周
```

示例：

- `0 3 * * *` 每天凌晨 3 点
- `*/30 * * * *` 每 30 分钟
- `0 */12 * * *` 每 12 小时

定时同步采用指纹对比：只有影片封面/顺序发生变化（或模板设置变更）时才重新生成，避免无意义地重复上传。

## 封面模板说明

当前内置「拼图模板」：深色渐变背景 + 顶部库名标题 + 强调色横线 + 影片数量副标题 + 影片封面网格。

可配置参数（默认值）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 宽度/高度 | 1000×1500 | 输出尺寸（px），建议保持 2:3 海报比例 |
| 列数 | 3 | 海报网格列数 |
| 最多影片数 | 9 | 取多少部影片封面 |
| 标题/副标题字号 | 84 / 36 | 按输出宽度等比缩放 |
| 圆角 / 边框 | 20 / 2 | 海报圆角与描边 |
| 背景顶部/底部 | #17233d / #0a0f1c | 垂直渐变 |
| 强调色 | #00a4dc | 标题下的横线 |
| 标题/副标题颜色 | #ffffff / #c9d6f2 | 文字颜色 |
| 字体 | Noto Sans CJK SC | 支持自定义字体文件路径 |
| 显示数量副标题 | 开 | 如「共 9 部作品」 |

## 常见问题

### 中文标题显示为方块/乱码

容器内已内置 Noto Sans CJK 中文字体；若使用自定义镜像或本地运行，请确认系统有中文字体，并在「设置」中填写字体文件路径。

### 封面已生成但没有写回 Emby

日志会显示「上传失败」及原因，多为 API 密钥权限不足或该 Emby 版本不支持直接为媒体库上传图片。封面会保留在本机 `data/covers/` 目录，可在界面中直接下载后到 Emby 手动设置。

### 支持 Jellyfin 吗

API 与 Emby 基本兼容，理论上可用；如需稳定支持建议以 Emby 为准。

### 修改封面模板后没有变化

模板设置已保存后，需执行一次「立即同步」或等待定时任务（设置变更本身会触发重新生成）。

## 安全提示

默认不启用访问令牌，任何能访问 3000 端口的人都可以操作。建议在「设置 → 访问令牌」中开启，或部署在可信内网/反代之后。

## 开发与测试

```bash
npm install
npm run mock    # 启动模拟 Emby 服务器（端口 8199）
npm start       # 启动封面工坊（端口 3000）
npm test        # 端到端集成测试（模拟 Emby 全流程）
```

## 目录结构

```
src/
  server.js          # HTTP 服务与 API 路由
  config.js          # 配置与环境变量
  store.js           # JSON 持久化（设置/合集状态/日志）
  scheduler.js       # cron 解析与定时任务
  emby/client.js     # Emby API 客户端
  covers/generator.js# 封面合成（sharp）
  covers/fonts.js    # 字体自动发现
  services/sync.js   # 同步/生成/上传核心逻辑
  services/webhook.js# Webhook 防抖调度
public/              # 管理界面（原生 HTML/CSS/JS）
scripts/
  mock-emby.js       # 模拟 Emby 服务器
  test-integration.js# 端到端测试
data/                # 运行数据（docker 挂载卷）
  db.json            # 设置与合集状态
  covers/            # 生成的封面
  cache/             # 影片封面缓存
```
