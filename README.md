# Emby 封面工坊

一个专门为 Emby 媒体库/合集自动生成封面的工具。它会从媒体库与合集内的影片中挑选一张海报，按模板合成新封面（海报 + 库名标题 + 数量副标题），并通过 Emby API 自动写回。支持 Webhook 入库自动更新、cron 定时更新与手动批量更新，Docker 一键部署，内置中文字体。

> 代码仓库：<https://github.com/4202217/EmbyCoverStudio>
> Docker 镜像：<https://hub.docker.com/r/kevindo2/emby-cover-studio>

## 功能特性

- 🔌 通过 API 密钥连接 Emby，自动发现所有媒体库与合集（含总合集 BoxSets）
- 🖼️ 单图海报封面：按「最新入库 / 最新发行」挑选一部影片海报 + 库名标题 + 数量副标题
- 🎛️ 每个合集可单独设置选图依据，也支持多选/全选批量设置，切换后自动保存
- 🎨 可配置尺寸、背景模式（渐变 / 海报模糊）、颜色、字号、圆角、字体等
- ⚡ Webhook 精准更新：影片入库/更新/删除时，仅重新生成受影响的媒体库与合集；定位失败时自动全量兜底
- ⏰ cron 定时同步（默认每 6 小时），通过指纹对比只对发生变化的合集重新生成
- 📊 任务记录：持久化保存每次生成操作的序号、名称、类型、时间、触发方式与结果（失败原因），支持暂停/继续/取消
- 🏠 概览页统计：封面生成张数、任务触发次数、监控中的合集、最近同步状态等
- 🔔 自动更新状态面板：显示上次触发、上次结果、下次定时、最近错误，并支持发送测试通知验证 Webhook 链路
- 🔒 可选访问令牌，保护管理界面
- 📦 镜像已发布到 Docker Hub（amd64 / arm64），GitHub 推送 main 后自动构建推送

## 快速开始（Docker）

推荐直接使用已发布到 Docker Hub 的镜像，无需本地构建：

```bash
# 先创建目录
mkdir -p emby-cover-studio/data
cd emby-cover-studio

# 保存下面的 docker-compose.yml
docker compose up -d
```

`docker-compose.yml`：

```yaml
services:
  emby-cover-studio:
    image: kevindo2/emby-cover-studio:latest
    container_name: emby-cover-studio
    ports:
      - "9308:3000"
    volumes:
      - ./data:/app/data
    environment:
      - TZ=Asia/Shanghai
      - PORT=3000
    restart: unless-stopped
```

启动后打开 `http://服务器IP:9308`（端口可自行修改）。

首次启动会自动生成 Webhook 地址和访问令牌（如有），在「概览」或「设置」页可见。

### 更新镜像

Docker Hub 不会主动提示有新版，可以手动拉取并重启容器：

```bash
docker compose pull
docker compose up -d
```

或在 Docker 管理界面中拉取 `kevindo2/emby-cover-studio:latest` 后重新创建容器。每次向 GitHub main 分支推送代码，GitHub Actions 会自动构建并推送新镜像。

### 从源码构建（可选）

克隆仓库后，在项目根目录执行：

```bash
docker compose up -d --build
```

## 首次使用

1. 在 Emby 中创建 API 密钥：**控制台 → 高级 → API 密钥 → 新建 API 密钥**（需要管理员权限）。
2. 打开封面工坊界面 →「设置」。
3. 填写 Emby 服务器地址（如 `http://192.168.1.100:8096`，无需带 `/emby`）和 API 密钥。
4. 点击「测试连接」，确认成功。
5. 进入「合集管理」，勾选需要自动生成封面的媒体库/合集（默认新发现的全部启用）。
6. 点击「立即同步」或对单个合集点击「更新」。

生成成功后，封面会自动上传为 Emby 中对应媒体库/合集的封面图，在 Emby 首页即可看到效果。

## 封面说明

当前内置「单图海报」样式：深色渐变（或海报模糊）背景 + 顶部库名标题 + 强调色横线 + 数量副标题 + 一张挑选出来的影片海报。

- **选图依据**：默认按「最新入库」挑选，也可改为「最新发行」；每个合集可单独配置，勾选合集后会出现配置框，切换后自动保存
- **尺寸**：媒体库（含总合集）默认 1600×900（16:9 缩略图），普通合集默认 1000×1500（2:3 海报）
- **背景模式**：渐变色（自定义上下色）/ 海报渐变模糊色（从展示的海报取色并模糊）
- **小字信息**：每条合集下方显示生成时间、选图依据、影片数量，以及海报来源视频标题

可配置参数（全局默认值，在「设置 → 封面样式与默认尺寸」中修改）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 宽度/高度 | 1000×1500 | 输出尺寸（px），建议保持 2:3 或 16:9 |
| 标题/副标题字号 | 84 / 36 | 按输出宽度等比缩放 |
| 圆角 / 边框 | 20 / 2 | 海报圆角与描边 |
| 背景模式 | 渐变色 | 渐变或海报模糊 |
| 背景顶部/底部 | #17233d / #0a0f1c | 垂直渐变 |
| 强调色 | #00a4dc | 标题下的横线 |
| 标题/副标题颜色 | #ffffff / #c9d6f2 | 文字颜色 |
| 字体 | Noto Sans CJK SC | 支持自定义字体文件路径 |
| 显示数量副标题 | 开 | 如「共 18 部影片」/「共 5 合集」 |

## 配置 Webhook（入库自动更新）

1. 在 Emby 安装官方 **Webhooks** 插件（控制台 → 插件 → 目录 → Webhooks）。
2. 在插件设置中，URL 填写封面工坊「概览」或「设置」页显示的 Webhook 地址（带 token）。
3. 事件建议勾选：**项目已添加（Item Added）**、**项目已更新（Item Updated）**、**项目已移除（Item Removed）**、**媒体库新建（Library New）**。
4. 保存后，影片入库/更新时会自动定位受影响的媒体库与合集，仅更新相关封面（默认防抖 20 秒，可在设置中调整）；若无法定位则自动执行全量同步兜底。

「设置 → 自动更新」中的「发送测试通知」按钮会模拟 Emby 推送一个事件，可用于验证整条 Webhook 链路是否正常，并会安排一次自动同步。

> 如果没有安装 Webhooks 插件，定时同步（默认每 6 小时）仍然会兜底更新封面。

## 定时更新

「设置 → 自动更新」中的 cron 表达式默认 `0 */6 * * *`（每 6 小时），支持标准 5 段格式：

```
分 时 日 月 周
```

示例：

- `0 3 * * *` 每天凌晨 3 点
- `*/30 * * * *` 每 30 分钟
- `0 */12 * * *` 每 12 小时

定时同步采用指纹对比：只有影片封面/顺序发生变化（或模板设置变更）时才重新生成，避免无意义地重复上传。

## 常见问题

### 中文标题显示为方块/乱码

容器内已内置 Noto Sans CJK 中文字体；若使用自定义镜像或本地运行，请确认系统有中文字体，并在「设置」中填写字体文件路径。

### 封面已生成但没有写回 Emby

日志会显示「上传失败」及原因，多为 API 密钥权限不足或该 Emby 版本不支持直接为媒体库上传图片。封面会保留在本机 `data/covers/` 目录，可在界面中直接下载后到 Emby 手动设置。

### Docker 镜像不会提示有更新

这是 Docker Hub 的默认行为。手动执行 `docker compose pull && docker compose up -d`，或在 Docker 管理界面拉取 `latest` 标签后重建容器即可。

### 支持 Jellyfin 吗

API 与 Emby 基本兼容，理论上可用；如需稳定支持建议以 Emby 为准。

### 修改封面模板后没有变化

模板设置已保存后，需执行一次「立即同步」或等待定时任务（设置变更本身会触发重新生成）；也可以使用「保存并重新生成全部封面」。

## 安全提示

默认不启用访问令牌，任何能访问服务端口的人都可以操作。建议在「设置 → 访问令牌」中开启，或部署在可信内网/反代之后。

## 目录结构

```
src/
  server.js          # HTTP 服务与 API 路由
  config.js          # 配置与环境变量
  store.js           # JSON 持久化（设置/合集状态/任务记录/日志）
  scheduler.js       # cron 解析与定时任务
  emby/client.js     # Emby API 客户端
  covers/generator.js# 封面合成（sharp）
  covers/fonts.js    # 字体自动发现
  covers/styles.js   # 封面样式与尺寸预设
  services/sync.js   # 同步/生成/上传核心逻辑
  services/webhook.js# Webhook 防抖调度与精准定位
public/              # 管理界面（原生 HTML/CSS/JS）
scripts/
  mock-emby.js       # 模拟 Emby 服务器
  test-integration.js# 端到端测试
data/                # 运行数据（docker 挂载卷）
  db.json            # 设置、合集状态、任务记录与日志
  covers/            # 生成的封面
  cache/             # 影片封面缓存
```
